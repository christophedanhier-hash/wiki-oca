## Structure de travail proposée

À partir de ces sources, les contenus seront répartis dans :

- `connaissances/` : notions astronomiques structurées par thème ;
- `fiches-revision/` : objectifs, définitions, cartes mémoire et questions-réponses ;
- `preparation-observations/` : repérage du ciel et pratique de terrain ;
- `pedagogie/` : formulation accessible et réponses aux questions du public ;
- `supports-animation/` : supports destinés à une animation ou à une observation guidée.

## Règles de traçabilité

- Les PDF restent les sources de référence ; le wiki ne les remplace pas.
- Chaque fiche produite indiquera le document source et, si possible, les pages concernées.
- Les faits issus du syllabus seront séparés des recommandations pédagogiques de Gérard.
- Les exigences d’évaluation seront distinguées des compléments facultatifs.
- Toute information absente des documents ou nécessitant validation par le formateur sera marquée explicitement.

## Limites de cet inventaire

- Le contenu du dossier Drive peut évoluer ; cet inventaire devra être resynchronisé après ajout ou modification de fichiers.
- Les objectifs détaillés n’ont pas encore été transcrits dans des fiches de révision.
